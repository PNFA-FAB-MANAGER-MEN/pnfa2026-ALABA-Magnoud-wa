## Appris 
- Le prototype est basé sur un XIAO ESP32-S3, un écran OLED et un module ECG AD8232.
- On a aussi commencé à travailler sur le capteur EMG à 5 broches (+Vs, GND, -Vs, SIG, GND) et sur la façon de le connecter au XIAO.
- L’objectif global était un projet Sport Monitor School, avec XIAO + capteurs + OLED + LED RGB.
- le module AD 8232 n'arrive pas a detecter le BPM
- réalisation du circuit électronique sur le site cirkitdesign
- ![image](../medias/desing%20circdes1.JPG)
- simulation du schema avec essaie de quelque composants sur circuitdesign
- nous avons changé le AD8232 par le MAX30102 qui est le capteur de frequence cardiaque
- On a testé le MAX30102 en MicroPython avec le XIAO.
- Ensuite, on l’a associé à son OLED SSD1306 128×64 pour afficher la fréquence cardiaque (BPM).
On a défini les seuils du prototype : < 60 BPM = bas, 60–100 = normal, > 100 = élevé.
